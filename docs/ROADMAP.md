# Roadmap

Milestones describe completed project increments, not promises about exact feature sets or dates.

| Version | Increment |
| --- | --- |
| v0.0.x | Foundation: identity, repository layout, CLI scaffolding |
| v0.1 | Daily Spanish foundation: root command, daily entry, translation, metadata, deterministic selection, curated starter content |
| v0.2 | Content library: browsing, search, filters, saved entries, history |
| v0.3 | Corpus and data foundation: validation, imports, statistics, quality reports; tagging begins |
| v0.4 | Vocabulary and personal collection with local persistence |
| v0.5 | Review sessions and learning history |
| v0.6 | Spanish linguistic analysis |
| v0.7 | Content representation and discovery |
| v0.8 | Personalised recommendations |
| v0.9 | Terminal experience and experimental integration, including the optional TUI and Mojo experiment |

Areas beyond the initial roadmap are recorded in the project specification and are not commitments for a particular release.
