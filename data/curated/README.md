# Curated content

The canonical entry collection served by the Rust application.

`entries.jsonl` contains 20 traditional Spanish refranes and sayings. Every entry has a stable identifier, an English translation marked as draft, an anonymous source statement, a licence statement, tags, and one or more vocabulary items.

These entries are drafts. The translations need human review, and a public domain collection citation still needs to be verified and recorded in `data/raw/`. No author is attributed because these are traditional anonymous expressions. Do not promote a translation to reviewed status until it has been checked.

The Rust application embeds this file at build time and does not require Python.
